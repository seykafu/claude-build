# claude-build

Kasey's Claude Code plugin marketplace. One plugin so far:

- [`astra-build`](plugins/astra-build/README.md): Claude Opus scopes, specs, checks, reviews and lands; GPT-6.2 Astra
  writes all code through Codex, one worktree per task.

```bash
claude plugin marketplace add /Users/kasey/Code/claude-build   # or the GitHub repo, once pushed
claude plugin install astra-build@claude-build
```
